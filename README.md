PKB — локальное веб-приложение на Go для личной базы знаний, которую в будущем сможет использовать AI-агент.

Основной pipeline первой версии:

```text
raw text -> processing job -> classification -> knowledge/unknown
```

Пользователь вводит сырой текст через web UI, backend сохраняет исходное сообщение в SQLite, создает processing job, а worker должен классифицировать сообщение через AI classifier. Если подходящий топик найден, результат попадает в `knowledge_items`; если нет, запись должна попасть в системный топик `unknown`.

SQLite — главный источник правды. Все важные данные должны храниться в SQLite. Markdown/Obsidian export и vector index, если появятся позже, должны быть только производными представлениями, которые можно пересобрать из SQLite.

## Текущее состояние

- Локальный HTTP-сервер на Go.
- SQLite-хранилище с миграциями.
- Web UI для создания, просмотра и удаления топиков.
- Системный топик `unknown`.
- Заготовки для обработки сообщений, jobs и классификации.
- Message pipeline и AI-классификация еще находятся в разработке.

## Что пока не входит в проект

На текущем этапе не делаются Telegram-интеграция, Obsidian export, vector search, voice, documents, agents, Redis, Kafka, Postgres и сложная архитектура.

## Требования

- Go 1.23 или новее.
- Отдельный SQLite CLI не обязателен: проект использует embedded SQLite driver `modernc.org/sqlite`.

## Запуск локально

```sh
go run ./cmd/pkb
```

По умолчанию приложение запускается на:

```text
http://localhost:8080
```

## Конфигурация

Настройки читаются из переменных окружения:

| Переменная | Значение по умолчанию | Описание |
| --- | --- | --- |
| `PKB_ADDR` | `:8080` | Адрес HTTP-сервера. |
| `PKB_DATA_DIR` | `data` | Директория для локальных данных. |
| `PKB_SQLITE_PATH` | `data/pkb.sqlite3` | Путь к SQLite базе. Если переменная пустая, путь собирается из `PKB_DATA_DIR`. |
| `PKB_SHUTDOWN_TIMEOUT` | `5s` | Таймаут graceful shutdown. |

Пример запуска с отдельной базой:

```sh
PKB_SQLITE_PATH=data/dev.sqlite3 go run ./cmd/pkb
```
