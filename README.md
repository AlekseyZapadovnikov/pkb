# PKB

PKB (Personal Knowledge Base) — локальное приложение на Go для личной базы знаний пользователя и доступа к ней ИИ-агентов. Пользователь добавляет заметки через web UI, а ИИ обрабатывает их и связывает с топиками.

**Проект ещё не готов и находится в активной разработке.**

## Стек

- **Backend:** Go, `net/http`, chi.
- **Хранилище:** SQLite, go-sqlite3, sqlx; миграции — goose.
- **Поиск:** sqlite-memory и sqlite-vector, локальная модель эмбеддингов.
- **Web UI:** Go HTML templates, CSS, JavaScript.
- **ИИ:** классификация через Codex CLI; доступ агентов — MCP Go SDK и Streamable HTTP.
- **Логи:** `log/slog`, JSON-записи в файл.

## Архитектура

Приложение работает в одном процессе: HTTP-сервер обслуживает web UI и MCP на `/mcp`, а фоновый worker обрабатывает задания классификации. SQLite — единственный обязательный источник данных.

| Каталог | Назначение |
| --- | --- |
| `cmd/pkb` | Точка входа. |
| `internal/app` | Сборка зависимостей, настройка логгера и запуск приложения. |
| `internal/usecase` | Доменные модели и сервисы обработки сообщений, знаний и топиков. |
| `internal/adapters` | Web, MCP, SQLite и клиент ИИ. |
| `migrations`, `prompts` | Схема базы данных и промпты классификатора. |
